# Estado del manifiesto de fuentes

`resolveSourceManifestSnapshot` proporciona una frontera mínima entre la
bibliografía privada declarada y las capas que requieren evidencia adicional.

- `declared`: el manifiesto tiene identificadores y títulos válidos.
- `blocked`: el manifiesto está vacío o presenta errores estructurales.

El estado no representa acceso al texto, lectura de capítulos, estructura
editorial verificada ni permiso para exponer contenido narrativo.
