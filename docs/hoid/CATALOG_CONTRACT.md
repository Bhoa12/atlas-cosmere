# Hoid IA: private source catalog

The catalog records bibliographic metadata for private EPUB sources. It is intentionally separate from narrative evidence.

## Security boundary

Catalog membership means only that a work is known to the application. It does not mean the full text is available, that a passage was consulted, or that a model may use prior knowledge as if it came from the source.

Narrative claims continue through:

**progress → context selection → authorized evidence → knowledge boundary → provider → verification**

The catalog stores identifiers, titles and structural book membership only. It has no field for excerpts or source text.

## Private bibliography

The contract can represent the verified cosmere.epub collection and the separate Roshar EPUBs, including the five main novels, Danzante del Filo and Esquirla del amanecer. Exact narrative content is not embedded. If a passage is unavailable, downstream components must abstain rather than inventing or claiming to have consulted it.
