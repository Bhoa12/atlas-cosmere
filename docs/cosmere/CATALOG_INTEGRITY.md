# Integridad del catálogo

La integridad del catálogo exige que cada obra declarada tenga una única relación explícita de procedencia bibliográfica.

## Lo que valida

- enlaces a obras que existen en el catálogo;
- ausencia de procedencia para una obra;
- enlaces duplicados para una misma obra.

## Lo que no valida

Esta capa no lee EPUBs ni prueba que una obra haya sido inspeccionada. Tampoco crea capítulos, unidades de lectura, resúmenes o hechos narrativos. La verificación editorial debe realizarse por separado a partir de material realmente accesible.

Las relaciones con fuentes se mantienen explícitas para evitar que el sistema asigne automáticamente una fuente por similitud de título o por inferencia.
