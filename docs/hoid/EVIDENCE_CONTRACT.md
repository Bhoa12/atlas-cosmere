# Contrato de evidencia de Hoid IA

Esta frontera representa una pieza de conocimiento disponible para una respuesta.

## Requisitos

La evidencia debe declarar un identificador, obra, capítulo, accesibilidad y un resumen original. Para un progreso dado solo se autoriza evidencia de la misma obra, en un capítulo ya leído y marcada como accesible.

## Fallo cerrado

La evidencia futura o inaccesible no se entrega al proveedor. La ausencia de evidencia autorizada debe conducir a abstención, nunca a completar la respuesta con conocimiento no autorizado.
