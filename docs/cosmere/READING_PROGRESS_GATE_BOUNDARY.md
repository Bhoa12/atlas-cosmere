# Reading progress and spoiler gates

This module is deliberately editorially neutral. It evaluates opaque identifiers only: a gate can be revealed when all of its required reading-unit identifiers are present in progress for the same work.

It does not define chapters, page locations, plot events, worlds, chronology, or reading order. Those relationships must be supplied by separately verified metadata. Invalid identifiers, mismatched works, and duplicate progress fail closed.

The boundary is suitable for future Scadrial, Sel, Nalthis, Taldain, Roshar, and additional-world registries without asserting any editorial relationship by itself.
