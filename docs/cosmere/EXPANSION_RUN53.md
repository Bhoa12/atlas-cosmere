# Expansión Cosmere: evaluación conservadora de spoilers

Este módulo añade una evaluación reutilizable para contenido protegido por progreso de lectura.

- No contiene texto de EPUB ni pasajes protegidos.
- No asigna obras a mundos por inferencia.
- Las unidades deben llegar como metadatos explícitos y verificables.
- La política es **fail-closed**: datos ausentes, incompatibles, duplicados o incompletos mantienen el contenido bloqueado.
- El catálogo bibliográfico proporcionado puede alimentar obras y fuentes, pero una fuente privada declarada no demuestra que su contenido interno haya sido inspeccionado.

El evaluador es independiente de Scadrial, Sel, Nalthis, Taldain, Roshar u otros mundos, por lo que puede reutilizarse cuando existan relaciones editoriales respaldadas.
