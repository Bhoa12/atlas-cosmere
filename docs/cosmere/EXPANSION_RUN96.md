# EXPANSION RUN 96

Esta iteración añade una capa reutilizable para validar puertas anti-spoilers y reconciliar progreso sin inferir contenido editorial.

## Garantías

- Las puertas con requisitos vacíos, duplicados, desconocidos o pertenecientes a otra obra quedan bloqueadas.
- El progreso se filtra por obra y se devuelve según el orden explícito de las unidades.
- El desbloqueo exige que todos los requisitos válidos estén completados.

Las funciones no introducen capítulos, resúmenes ni hechos narrativos. Las fuentes privadas pueden seguir registrándose como catálogo, pero esta capa no afirma haber inspeccionado pasajes no accesibles.
