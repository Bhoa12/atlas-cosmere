# Expansión Cosmere — Run 91

Esta iteración añade una auditoría transversal para la expansión del Atlas.

## Modelo

La auditoría valida conjuntamente:

`fuentes → obras → unidades de lectura → progreso → puertas anti-spoilers`

Los datos bibliográficos privados o procedentes de un índice verificado pueden permanecer en el catálogo, pero no autorizan por sí mismos estructura interna ni resúmenes narrativos.

## Procedencia

Una unidad de lectura solo es válida cuando su fuente es `editorial-accessible` y está marcada como accesible. Las referencias desconocidas, los identificadores duplicados y las posiciones duplicadas se informan como incidencias.

## Anti-spoilers

Las puertas se validan contra unidades de la misma obra y se desbloquean únicamente cuando todos sus requisitos válidos están completados. Los requisitos vacíos, duplicados o desconocidos permanecen bloqueados.

Las pruebas usan datos sintéticos y no reproducen texto protegido ni afirman acceso a pasajes privados.
