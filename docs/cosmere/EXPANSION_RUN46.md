# Expansion run 46

This layer separates source provenance, worlds, works, reading units, progress and spoiler gates.

## Editorial boundary

World identifiers are navigation metadata only. The model does not infer work-to-world relationships from titles, filenames or general narrative knowledge. Reading units are explicit records and must not be treated as invented chapters.

A `verified-index` source supports only metadata supplied by a verified index. A `declared-private` source records availability without claiming its internal text was inspected.

No protected EPUB text, quotations or copied passages are stored here. Spoiler gates are fail-closed: missing, duplicate or cross-work requirements keep content locked.
