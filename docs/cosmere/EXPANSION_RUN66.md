# Expansión Cosmere: Run 66

Esta iteración añade una capa de dominio reutilizable para **mundos, obras, unidades de lectura, progreso y puertas anti-spoilers**.

## Principios

- Las puertas anti-spoilers son *fail-closed*: requisitos vacíos, duplicados o desconocidos nunca desbloquean contenido.
- El progreso se normaliza antes de evaluarse para descartar unidades desconocidas y duplicadas.
- Las relaciones mundo–obra solo se muestran cuando están declaradas explícitamente; los títulos no se usan para inferir pertenencia.
- El catálogo incluido en el código es bibliográfico: los títulos proceden del índice verificado aportado por el usuario.
- Las fuentes privadas declaradas no se tratan como contenido inspeccionado.

No se almacena ni copia texto íntegro de EPUBs protegidos. Cualquier resumen futuro debe ser original y estar respaldado por material realmente accesible.
