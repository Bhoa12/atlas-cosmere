# Abstención segura

La abstención es una salida de primera clase de Hoid IA. No es un error que deba ocultarse ni una invitación a completar una respuesta con conocimiento general.

## Regla de fallo cerrado

Cuando falte progreso válido, evidencia autorizada o procedencia verificable, el sistema devuelve una abstención estructurada. Un fallo del proveedor tampoco autoriza una respuesta alternativa.

## Límite de contenido

Esta capa no lee ni almacena texto íntegro de EPUBs privados. Solo comunica el estado de seguridad de una consulta y puede combinarse con los contratos de progreso, alcance por capítulo, contexto autorizado y procedencia.
