# Private Bibliography Catalog

`COSMERE_EPUB_BIBLIOGRAPHY` is the explicit metadata catalog for the verified index declared for the private `cosmere.epub` collection.

## Scope

The manifest records only:

- stable technical identifiers;
- the declared work title;
- the source collection identifier;
- the structural access status already represented by the source model.

It deliberately does **not** contain excerpts, chapter text, summaries, world assignments, chronology, or narrative facts.

## Safety boundary

Catalog membership is not evidence that a passage was read in the current environment. Any narrative summary still has to pass the independent evidence and anti-spoiler gates.

The manifest does not infer missing entries from filenames or external editorial knowledge. Roshar sources remain represented by their separate private-source catalog until explicit, verified metadata is available to the runtime.
