# Evidence-backed spoiler gate

This gate combines three independent requirements before narrative content may be revealed:

1. a source must exist in the declared private-source catalogue;
2. an explicit evidence record must identify an original summary through a non-empty summary identifier;
3. the reader must have reached the required reading unit through contiguous validated progress.

The gate is intentionally fail-closed. Bibliographic presence, metadata evidence, an unknown evidence identifier, or insufficient progress all deny disclosure.

No EPUB passage, quotation, chapter text, or narrative claim is stored by this layer. A registered summary identifier records provenance only; it does not assert that inaccessible source text was consulted.
