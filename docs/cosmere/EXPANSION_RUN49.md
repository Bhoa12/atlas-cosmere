# Cosmere expansion run 49

This layer separates source provenance, worlds, works, reading units, progress and spoiler gates.

## Editorial boundary

The verified private index supports only the listed work metadata. Private Roshar EPUBs are registered as declared sources without claiming that internal passages were inspected. World membership, chapter structure and narrative facts are not inferred from titles or filenames.

No protected text is stored. Future summaries must be original and backed by accessible evidence. If a passage is unavailable, the application must leave the related fact absent rather than invent it.

## Spoiler policy

`canReveal` fails closed: empty or duplicate requirements, cross-work progress and unknown units remain locked.
