# Validación integral de expansión

La validación integral agrega comprobaciones técnicas sobre catálogo, secuencias declaradas, progreso y, cuando se proporciona, cobertura de procedencia.

La procedencia es opcional para permitir validar estructuras parciales sin inventar fuentes. Cuando existe, se comprueba que cada obra declarada tenga un enlace explícito y que ningún enlace apunte a una obra inexistente.

Este módulo trabaja únicamente con metadatos e identificadores. No interpreta EPUBs, no copia texto protegido, no deduce cronologías y no crea capítulos, obras ni puntos de desbloqueo.
