# EXPANSION RUN 94

Esta iteración añade una capa **catalog-first** para la expansión de Atlas del Cosmere.

## Alcance

- Registra títulos como metadatos bibliográficos.
- Valida identidades y procedencia de obras.
- Mantiene las fuentes privadas declaradas separadas del contenido accesible.

## Límites deliberados

El catálogo no infiere mundos, cronologías, capítulos, unidades de lectura ni hechos narrativos. Los títulos procedentes del índice verificado de `cosmere.epub` se almacenan únicamente como catálogo. Los EPUB privados de Roshar permanecen declarados como fuente privada y no se tratan como texto inspeccionado.

Las pruebas usan únicamente datos sintéticos y metadatos.
