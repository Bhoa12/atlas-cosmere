# Contrato de incorporación segura de mundos

Este documento define el orden de integración para ampliar Atlas del Cosmere sin convertir una entrada bibliográfica en contenido narrativo.

## Capas

1. **Catálogo**: registra únicamente metadatos e identificadores de fuentes disponibles.
2. **Asociación estructural**: relaciona identificadores de obras y mundos mediante evidencia declarada.
3. **Unidades de lectura**: incorpora posiciones únicamente cuando su estructura esté respaldada.
4. **Progreso**: acepta solo prefijos contiguos y datos no ambiguos.
5. **Puertas anti-spoilers**: desbloquean contenido solo después de validar las capas anteriores.

## Regla fail-closed

Si una obra, asociación, unidad o estado de progreso falta, es ambiguo o resulta inconsistente, el contenido dependiente debe permanecer bloqueado.

## Alcance editorial

La presencia de una fuente privada en el catálogo no prueba que su texto haya sido leído ni autoriza a generar capítulos, hechos, citas o resúmenes. Los resúmenes deben ser originales y respaldados por evidencia accesible.

## Orden recomendado

Para cada mundo nuevo: registrar catálogo -> validar asociaciones -> incorporar estructura de lectura respaldada -> validar progreso -> conectar desbloqueos.

Este contrato es reutilizable para Scadrial, Sel, Nalthis, Taldain, Roshar y futuros mundos.
