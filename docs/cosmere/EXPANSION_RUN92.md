# Expansión Cosmere — Run 92

Esta iteración añade una capa de dominio única para validar **fuentes, mundos, obras, relaciones explícitas, unidades de lectura, progreso y descriptores de contenido**.

## Principios

- Los mundos son entidades independientes. Scadrial, Sel, Nalthis, Taldain y Roshar pueden registrarse sin inferir obras a partir de sus títulos.
- Las relaciones obra–mundo son explícitas y auditables.
- Un índice verificado sirve para metadatos de catálogo, no para inventar capítulos o hechos narrativos.
- Las unidades de lectura requieren una fuente editorial realmente accesible.
- Los resúmenes originales requieren respaldo editorial accesible; una fuente privada declarada pero no accesible no basta.
- Las puertas anti-spoilers fallan de forma cerrada: requisitos vacíos, duplicados o desconocidos mantienen el contenido bloqueado.

Las pruebas usan datos sintéticos. No se incluye ni reproduce texto protegido de los EPUB privados.
