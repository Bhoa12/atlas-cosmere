# Expansión Cosmere — Run 97

Esta iteración introduce un manifiesto transversal para validar referencias entre mundos, obras, relaciones explícitas, unidades de lectura y puertas anti-spoilers.

## Principios

- Las asignaciones obra-mundo nunca se deducen del título.
- Las unidades solo se aceptan cuando su fuente está declarada como accesible por el manifiesto.
- La auditoría no crea capítulos, cronologías ni hechos narrativos.
- Las puertas anti-spoilers son *fail-closed*: requisitos vacíos, duplicados, desconocidos o de otra obra mantienen el contenido bloqueado.
- El progreso se reconcilia por obra y según posiciones explícitas.

Las pruebas emplean exclusivamente datos sintéticos. Esta capa es reutilizable para Scadrial, Sel, Nalthis, Taldain, Roshar y futuros mundos sin incorporar texto protegido.
