# Cosmere expansion run 52

This run adds a reusable, source-safe model for worlds, works, reading units, progress and spoiler gates.

## Evidence boundary

The verified index of `cosmere.epub` is represented as metadata only. The Roshar collection is recorded as a declared private source without claiming inspection of its internal text.

World assignments are optional and are never inferred from a title, filename, or private-source declaration. Reading units are also optional and must be supplied as explicit metadata.

## Spoiler policy

`canReveal` fails closed: missing requirements, duplicate requirements, a different work, unknown units, or incomplete progress all keep content locked.

No protected EPUB text, quotations, or copied passages are stored by this model. Future summaries must be original and backed by accessible evidence.
