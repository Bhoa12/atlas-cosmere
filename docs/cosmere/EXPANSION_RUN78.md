# Expansión Cosmere: run78

Esta iteración añade una capa reutilizable para conectar mundos, obras, unidades
de lectura, progreso y puertas anti-spoilers sin convertir el catálogo
bibliográfico en contenido editorial.

## Principios

- Una obra solo aparece vinculada a un mundo cuando la relación se proporciona
  explícitamente.
- La capa no deduce mundos, capítulos, cronologías ni hechos narrativos a partir
  de títulos.
- El progreso se reconcilia únicamente contra unidades explícitas de la obra.
- Las puertas anti-spoilers fallan de forma cerrada ante requisitos vacíos,
  duplicados o desconocidos.

## Fuentes

El índice verificado de cosmere.epub puede seguir utilizándose para registrar los
títulos aportados como metadatos. Los EPUB privados de Roshar pueden registrarse
como fuentes declaradas sin afirmar que sus pasajes o estructura interna hayan
sido consultados.

Esta capa no almacena texto protegido ni genera resúmenes narrativos. Cualquier
contenido editorial futuro debe ser original y estar respaldado por material
realmente accesible.

## Pruebas

Las pruebas usan exclusivamente datos sintéticos y comprueban la ausencia de
inferencia automática de mundos, la reconciliación conservadora del progreso y
el bloqueo anti-spoilers hasta completar todos los requisitos explícitos.
