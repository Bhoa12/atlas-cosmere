# Contrato de progreso de lectura

Esta capa transforma el progreso declarado por el lector en una frontera técnica mínima.

## Regla principal

Una pieza narrativa solo puede considerarse para una obra y capítulo si existe progreso explícito para esa misma obra y el capítulo solicitado es menor o igual al capítulo alcanzado.

## Fallo cerrado

- Obras sin progreso declarado: rechazadas.
- Capítulos futuros: rechazados.
- Progreso malformado: error explícito.

El contrato no almacena texto de EPUB, extractos ni hechos narrativos. La presencia de una obra en el catálogo bibliográfico no concede progreso ni autorización narrativa.
