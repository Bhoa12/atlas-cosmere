# Expansión Cosmere: run87

Esta iteración añade una capa de dominio pequeña y reutilizable para **fuentes, mundos, obras, unidades de lectura, progreso y puertas anti-spoilers**.

## Límites de procedencia

El índice verificado de `cosmere.epub` se trata como catálogo bibliográfico. No autoriza inferir capítulos, secciones ni hechos narrativos. Las fuentes privadas declaradas tampoco se consideran inspeccionadas automáticamente.

Una unidad de lectura solo se acepta cuando su fuente es `editorial-accessible` y está marcada como accesible. Las puertas anti-spoilers fallan de forma cerrada ante requisitos vacíos, duplicados o desconocidos.

## Mundos prioritarios

El modelo registra Scadrial, Sel, Nalthis, Taldain y Roshar como entidades independientes. La pertenencia editorial de una obra debe añadirse mediante relaciones explícitas respaldadas; esta iteración no inventa esas relaciones.

## Bibliografía

El catálogo de fuentes declarado por el usuario incluye las obras del índice verificado de `cosmere.epub` y los EPUB privados de Roshar. Esta documentación no afirma haber leído pasajes no accesibles ni reproduce texto protegido.

Las pruebas usan únicamente datos sintéticos y comprueban procedencia, aislamiento del progreso y desbloqueo conservador.
