# EXPANSION RUN 104

Esta iteración añade un manifiesto único y reutilizable para la expansión del Atlas del Cosmere.

## Modelo

`sources → works → worlds → links → reading units → progress → spoiler cards`

Las fuentes privadas declaradas pueden formar parte del catálogo, pero no autorizan por sí mismas unidades de lectura ni resúmenes narrativos. Esos elementos requieren una fuente marcada explícitamente como `editorial-accessible` y accesible.

## Política anti-spoilers

`visibleCards` aplica una política fail-closed: si el manifiesto no supera la auditoría, no se muestra ninguna tarjeta. Una tarjeta válida solo aparece cuando todo su conjunto explícito de unidades requeridas está completado para la misma obra.

## Límites editoriales

Esta capa no inventa capítulos, cronologías, relaciones entre obras y mundos ni hechos narrativos. La bibliografía aportada puede registrarse como catálogo de metadatos; cualquier estructura de lectura o resumen debe tener respaldo accesible y explícito.

Las pruebas utilizan exclusivamente datos sintéticos.
