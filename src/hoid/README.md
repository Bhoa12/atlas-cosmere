# Hoid IA

Base desacoplada de proveedores para Atlas del Cosmere.

## Seguridad contra spoilers
El conocimiento se etiqueta con una obra y un capítulo de desbloqueo. La recuperación compara exclusivamente el progreso de esa misma obra: avanzar en otro libro no desbloquea contenido.

Las fuentes privadas se representan únicamente mediante metadatos. No se incluyen EPUBs ni texto protegido. Un elemento de conocimiento debe incorporar un resumen original y una posición verificable antes de añadirse.

Si no hay proveedor configurado, el servicio falla de forma explícita y no simula una respuesta de IA.
