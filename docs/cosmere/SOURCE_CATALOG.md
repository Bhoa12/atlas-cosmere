# Catálogo de fuentes privadas y límites de procesamiento

## Propósito

Este manifiesto registra únicamente la bibliografía que el usuario ha puesto a
disposición del proyecto. No contiene texto de las obras, sinopsis copiadas ni
afirmaciones narrativas extraídas sin verificación.

## Estados

`catalogued` significa que la obra está registrada como fuente disponible en
la bibliografía aportada. No significa que su estructura interna haya sido
extraída ni validada.

`structure_verified` solo debe utilizarse después de comprobar una fuente
accesible y registrar unidades de lectura con localizadores reproducibles.

## Regla de protección

Los EPUB privados no se suben al repositorio. El código puede conservar IDs,
títulos, estructura de lectura validada y referencias de procedencia, pero no
texto íntegro protegido. Si una fuente no está accesible durante un ciclo de
trabajo, su contenido permanece pendiente y no se inventan hechos.


## Consulta por colección

La capa de catálogo puede agrupar obras por un identificador de colección declarado,
por ejemplo una fuente privada concreta. Antes de devolver resultados valida el
catálogo completo; si detecta metadatos duplicados o malformados devuelve una lista
vacía. Así una consulta parcial nunca convierte un catálogo inconsistente en una
señal de disponibilidad editorial.
