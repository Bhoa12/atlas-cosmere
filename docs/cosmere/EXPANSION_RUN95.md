# EXPANSION RUN 95

Esta iteración añade una capa reutilizable para conectar **obras y mundos únicamente mediante relaciones explícitas**.

## Garantías

- Los mundos prioritarios se modelan como entidades independientes: Scadrial, Sel, Nalthis, Taldain y Roshar.
- Una relación debe apuntar a una obra, mundo y fuente registrados.
- Las relaciones duplicadas, obras desconocidas y mundos desconocidos se rechazan.
- No existe inferencia por título ni generación automática de pertenencia a un mundo.

## Procedencia y límites

Esta capa valida referencias de catálogo; no convierte una fuente privada en texto editorial inspeccionado y no añade capítulos, cronologías, pasajes ni hechos narrativos. Las relaciones reales solo deben incorporarse cuando el proyecto disponga de respaldo adecuado.

Las pruebas utilizan exclusivamente datos sintéticos.
