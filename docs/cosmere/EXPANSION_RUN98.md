# EXPANSION RUN 98

Esta iteración añade consultas reutilizables sobre el catálogo bibliográfico.

## Alcance

- Búsqueda por identificador o título.
- Agrupación por fuente declarada.
- Normalización orientada al español para búsquedas de metadatos.

## Límites de procedencia

Estas funciones trabajan exclusivamente con los campos ya presentes en el catálogo. No deducen mundo, cronología, capítulos, unidades de lectura ni hechos narrativos a partir de un título o de una coincidencia.

Por tanto, la bibliografía privada declarada y el índice verificado continúan siendo fuentes de catálogo: su presencia no implica que el texto editorial haya sido inspeccionado ni autoriza a mostrar resúmenes no respaldados.
