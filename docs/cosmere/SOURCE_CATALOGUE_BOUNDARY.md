# Source catalogue boundary

This module records only bibliographic metadata explicitly verified for the project's private source packages.

## Guarantees

- Stable technical work identifiers.
- Human-readable titles supplied as verified catalogue metadata.
- Explicit source-package provenance.
- Fail-closed validation for malformed or duplicate metadata.

## Deliberate non-guarantees

The catalogue does **not** establish world membership, chronology, reading order, chapter/page boundaries, characters, events, or narrative summaries.

The five principal Roshar novels are known to exist in private EPUB sources, but their individual titles are intentionally not represented here unless verified metadata is added explicitly.

No protected source text is stored in this catalogue. Future reading units and spoiler gates must reference technical identifiers and independently verified structure rather than copying prose.
