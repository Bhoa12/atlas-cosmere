# Expansión Cosmere — Run 107

Se añade una auditoría reutilizable de integridad para mundos, obras y relaciones explícitas entre ambos.

## Límites

- No asigna una obra a un mundo por inferencia.
- Las relaciones deben declararse explícitamente y conservar una referencia de procedencia.
- La ausencia de una relación se informa como cobertura pendiente, no como error narrativo.
- Esta capa no contiene texto editorial, capítulos ni resúmenes de obras.

La bibliografía privada declarada puede seguir figurando como catálogo de fuentes sin convertirse automáticamente en evidencia editorial accesible.
