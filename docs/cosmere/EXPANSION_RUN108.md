# Expansión Cosmere — Run 108

Esta iteración añade una capa de navegación reutilizable entre mundos, obras y unidades de lectura.

## Principios

- Las relaciones obra-mundo son siempre explícitas.
- El sistema no deduce mundos a partir de títulos ni de heurísticas.
- Las unidades de lectura requieren una obra conocida, posición entera positiva, fuente identificada y accesibilidad explícita.
- Las unidades inaccesibles no entran en la navegación ni pueden utilizarse como estructura editorial.
- Los duplicados de relación y las posiciones repetidas se consideran errores, en lugar de resolverse silenciosamente.

La capa solo gestiona metadatos y estructura declarada. No contiene texto protegido ni genera hechos narrativos. Los resúmenes y tarjetas anti-spoilers siguen requiriendo respaldo editorial accesible.
