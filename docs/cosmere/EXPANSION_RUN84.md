# Expansión Cosmere — Run 84

Esta iteración añade una capa de dominio reutilizable para catálogo, unidades de lectura, progreso y puertas anti-spoilers.

## Procedencia

El índice verificado respalda títulos y metadatos. Una fuente privada declarada no se trata como inspeccionada. Solo una fuente marcada simultáneamente como `editorial-accessible` y accesible puede respaldar unidades de lectura.

## Catálogo

Se registran los 17 títulos declarados del índice de `cosmere.epub` como catálogo. Esta capa no deduce mundos, capítulos, cronologías ni hechos narrativos a partir de los títulos.

## Progreso y spoilers

La reconciliación ignora obras y unidades desconocidas y conserva el orden explícito. Las puertas anti-spoilers son fail-closed: requisitos vacíos, duplicados o desconocidos no desbloquean contenido.

Las pruebas usan únicamente datos sintéticos y no contienen texto protegido.
