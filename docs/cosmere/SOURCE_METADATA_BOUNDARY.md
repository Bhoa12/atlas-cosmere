# Catálogo de fuentes: frontera de metadatos

Esta frontera separa la bibliografía conocida de cualquier interpretación narrativa.

## Principio

Los títulos verificados pueden registrarse como metadatos. La existencia de un título en el catálogo no autoriza a inferir mundo, cronología, orden de lectura, capítulos, páginas ni hechos narrativos.

## Integridad

Una entrada debe tener un identificador técnico estable, un título no vacío y una procedencia de fuente conocida. Las validaciones deben fallar de forma cerrada: datos ambiguos, duplicados o malformados no se corrigen automáticamente.

## Protección de contenido

Los EPUB privados son fuentes de referencia. No se almacena texto íntegro protegido en este módulo. Las unidades internas y los resúmenes solo se añaden cuando estén respaldados por material accesible y verificable.
