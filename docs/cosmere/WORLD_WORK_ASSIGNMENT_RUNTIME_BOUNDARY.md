# Límite técnico de asignaciones mundo → obra

Este módulo valida relaciones técnicas entre identificadores de mundos e identificadores de obras.

## Garantías

- Solo acepta IDs canónicos.
- Rechaza mundos y obras desconocidos.
- Rechaza pares duplicados.
- Una lista vacía es válida: la ausencia de una asignación verificada **no** se convierte en una inferencia.

## Fuera de alcance

El módulo no afirma que una obra concreta pertenezca a un mundo, no establece cronología ni orden de lectura y no contiene hechos narrativos. Las relaciones reales deberán incorporarse únicamente desde metadatos verificados.

Los payloads editoriales y el texto protegido permanecen fuera de esta frontera técnica.
