# Cosmere expansion boundary

This module provides reusable technical records for sources, worlds, works, reading units and reading progress.

## Editorial boundary

Only explicitly supplied metadata should populate the catalogue. The infrastructure must not infer narrative facts, chapter structure, world membership, chronology or spoiler requirements from a title or file name.

Private sources may be represented as `declared-private`; that status does not claim their internal text was inspected.

## Spoiler boundary

Visibility is fail-closed: malformed or duplicate requirements/progress stay locked. Editorial layers define requirements; this module only evaluates them.

## Source catalogue use

The verified index supplied by the user can be represented as work metadata. No protected text is copied into this module.
