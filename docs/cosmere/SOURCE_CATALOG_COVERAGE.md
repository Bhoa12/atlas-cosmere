# Cobertura del catálogo de fuentes

`summarizeSourceCatalogCoverage` compara identificadores bibliográficos declarados con una lista explícita de identificadores esperados.

## Garantías

- informa de fuentes esperadas que faltan;
- informa de identificadores declarados que no pertenecen al conjunto esperado;
- elimina duplicados únicamente para el recuento técnico;
- no interpreta títulos como hechos narrativos;
- no afirma que una fuente haya sido leída, extraída o verificada editorialmente.

Esta utilidad sirve para controlar la integridad del catálogo privado antes de asociar metadatos, unidades de lectura o contenido protegido por anti-spoilers. La cobertura bibliográfica no constituye evidencia editorial.
