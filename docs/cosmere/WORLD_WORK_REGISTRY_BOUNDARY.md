# World–work registry boundary

This registry is infrastructure for explicit metadata relationships.

It validates world identifiers, work identifiers, optional work-to-world links, and source provenance identifiers. It does not infer a relationship from a title, a private EPUB filename, chronology, or narrative knowledge.

For the current private bibliography, world assignments must be added only when separately verified metadata is available. The registry can therefore represent Scadrial, Sel, Nalthis, Taldain, Roshar, and future worlds without claiming that any listed work belongs to one of them merely because that would be commonly expected.

The boundary is fail-closed: malformed identifiers, duplicates, unknown sources, and unknown worlds invalidate the registry. It contains no protected text, passages, chapter structure, or narrative summaries.
